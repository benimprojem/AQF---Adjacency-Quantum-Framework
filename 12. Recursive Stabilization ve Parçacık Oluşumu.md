# 12. Recursive Stabilization ve Parçacık Oluşumu

AQF’de parçacık:

[
\boxed{
\text{stable recursive eigenmode}
}
]

olarak tanımlanır.

Fundamental noktasal obje değildir.

---

# 12.1 Recursive Closure

Temel stabilizasyon mekanizması:

[
G_i
===

\sum_{p\in\Gamma_i}
e^{i\Phi_p}
]

Burada:

| sembol     | anlam                 |
| ---------- | --------------------- |
| (\Gamma_i) | recursive path kümesi |
| (\Phi_p)   | toplam faz            |
| (G_i)      | reinforcement gain    |

---

# 12.2 Constructive Reinforcement

Kararlı mod için:

[
\Phi_p\approx2\pi n
]

olmalıdır.

Bu durumda:

[
e^{i\Phi_p}\rightarrow1
]

ve recursive reinforcement büyür.

---

# 12.3 Destructive Leakage

Eğer:

[
\Phi_p\neq2\pi n
]

ise:

[
G_i\rightarrow0
]

yaklaşır.

Bu durumda:

* instability,
* decay,
* leakage

oluşur.

---

# 12.4 Stabilization Functional

Temel stabilization terimi:

[
\mathcal L_G
============

\gamma_G
\sum_i|G_i|^2
-------------

V(G_i)
]

Burada:

| terim     | anlam                   |
| --------- | ----------------------- |
| gain term | recursive reinforcement |
| (V(G))    | stabilization potential |

---

# 12.5 Stabilization Potential

Minimal form:

[
V(G)
====

-\mu|G|^2
+
\lambda|G|^4
+
\sigma|G|^6
]

olarak alınabilir.

---

# 12.6 Quartic Closure

[
-\mu|G|^2+\lambda|G|^4
]

terimi:

* localization,
* self-trapping,
* recursive closure

üretir.

Bu olmadan particle mode oluşmaz.

---

# 12.7 Sextic Saturation

[
+\sigma|G|^6
]

terimi runaway stabilizationı keser.

Bu nedenle:

* finite generation,
* metastability limit,
* shell cutoff

oluşur.

---

# 12.8 Critical Stabilization

Kararlı çözüm koşulu:

[
\frac{dV}{d|G|}=0
]

olur.

Yani:

[
-2\mu G
+
4\lambda|G|^2G
+
6\sigma|G|^4G
=============

0
]

---

# 12.9 Finite Shell Sonucu

Buradan:

[
|G|^2_{crit}
\sim
\frac{\lambda}{\sigma}
]

kritik stabilization seviyesi çıkar.

Bu seviyeden sonra:

* recursive overload,
* decoherence,
* shell collapse

oluşur.
